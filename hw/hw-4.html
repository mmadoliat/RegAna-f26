Diagnostics on Gasoline Mileage Data

We use the same data set mpg.csv from Homework 3. Consider the multiple regression model

\[ y=\beta_0+\beta_1x_1+\beta_6x_6+\epsilon, \]

where

  • \(y\): miles per gallon,
  • \(x_1\): engine displacement (cubic inches),
  • \(x_6\): number of carburetor barrels.

To import the data into R, use

mpg <- read.csv("/hw/data/mpg.csv")
fit <- lm(y ~ x1 + x6, data = mpg)

  1. Compare the externally studentized residuals (R-student residuals) \(t_i\) with a Student-\(t\) distribution using a Q-Q plot. Also produce a histogram and density plot of the \(t_i\)’s.

    Does there appear to be any serious problem with the normality assumption? Explain what you see in the plots.

  2. Apply the Box-Cox method to the gasoline mileage model and discuss whether a transformation of the response \(y\) appears necessary.

    Report the value of \(\lambda\) suggested by the Box-Cox analysis and explain how you reached your conclusion.

  3. Refit the model using

    • \(\lambda=0\), corresponding to the log transformation, and
    • the value of \(\lambda\) selected by the Box-Cox method.

    Compare the R-student residuals from

    • the original model,
    • the log-transformed model, and
    • the Box-Cox-selected transformed model

    using a boxplot.

    Does either transformation appear to improve the residual behavior? Explain.

  4. Construct

    • a plot of the R-student residuals \(t_i\) versus the fitted responses, and
    • Tukey’s spread-level plot.

    Is there any evidence of violation of the constant-variance assumption? Explain.

  5. Perform a formal test of constant variance using car::ncvTest().

    State the hypotheses

    \[ H_0:\text{constant variance} \]

    versus

    \[ H_1:\text{variance changes with }E(Y\mid X), \]

    report the test result, and explain your conclusion in context.

Influence Diagnostics on Squid Data

An experiment was conducted to study the size of squid eaten by sharks and tuna. The data set squid.csv contains the variables

  • \(x_1\): rostral length in inches,
  • \(x_2\): wing length in inches,
  • \(x_3\): rostral-to-notch length,
  • \(x_4\): notch-to-wing length,
  • \(x_5\): width in inches,
  • \(y\): weight in pounds.

To import the data into R, use

squid <- read.csv("/hw/data/squid.csv")
fit_squid <- lm(y ~ x1 + x2 + x3 + x4 + x5, data = squid)

  1. Perform a thorough leverage and influence analysis of the squid data.

    Compute

    • R-student residuals,
    • hat values,
    • Cook’s distance,
    • DFFITS,
    • DFBETAS, and
    • COVRATIO.

    You may use influence.measures() where helpful.

    Describe the guidelines you use to identify unusual or influential observations. Discuss the effect of the most important observations on

    • fitted values,
    • regression coefficients, and
    • precision of the coefficient estimates.

  2. Use graphical influence diagnostics for the squid model.

    1. Construct a bubble plot that displays residual size, leverage, and influence.

    2. Construct an influence index plot using car::influenceIndexPlot().

    Identify the observations that stand out in these plots and explain why they are noteworthy.

  3. Produce the added-variable plots for the five regressors using car::avPlots().

    Discuss the plots carefully.

    • Are there observations that appear influential for particular regression coefficients?
    • Are there observations that appear jointly influential across several added-variable plots?
    • Do the same observations appear important in the numerical influence diagnostics from Questions 6 and 7?

  4. Numerically verify the following properties of the added-variable plot for \(x_1\).

    Let \(x_{(1)}\) denote all regressors except \(x_1\), let

    \[ e(y\mid x_{(1)}) \]

    be the residuals from regressing \(y\) on \(x_{(1)}\), and let

    \[ e(x_1\mid x_{(1)}) \]

    be the residuals from regressing \(x_1\) on \(x_{(1)}\).

    Verify numerically that:

    1. The slope of the least-squares simple regression of \(e(y\mid x_{(1)})\) on \(e(x_1\mid x_{(1)})\) is the same as the least-squares coefficient \(b_1\) for \(x_1\) in the full multiple regression.

    2. The residuals from the simple regression of \(e(y\mid x_{(1)})\) on \(e(x_1\mid x_{(1)})\) are the same as the residuals from the full multiple regression.

    3. The standard error of \(b_1\) satisfies

    \[ SE(b_1) = \frac{s} {\sqrt{\sum_{i=1}^n e_i^2(x_1\mid x_{(1)})}}, \]

    where

    \[ s=\sqrt{MS_{\mathrm{res}}} \]

    is obtained from the full multiple regression.

Mathematical Derivation and Reasoning

  1. Consider a multiple linear regression model with an intercept, and let

\[ \mathbf H = \mathbf X(\mathbf X'\mathbf X)^{-1}\mathbf X' \]

be the hat matrix. Show that each leverage value satisfies

\[ \boxed{ \frac{1}{n}\le h_{ii}\le 1 }. \]

Your proof should clearly justify both bounds.

For the lower bound, you may use the representation

\[ h_{ii} = \frac{1}{n} + (\mathbf z_i-\bar{\mathbf z})' \left[ \sum_{j=1}^n (\mathbf z_j-\bar{\mathbf z}) (\mathbf z_j-\bar{\mathbf z})' \right]^{-1} (\mathbf z_i-\bar{\mathbf z}), \]

where \(\mathbf z_i\) contains the non-intercept predictors.

For the upper bound, use the facts that \(\mathbf H\) is symmetric and idempotent. In particular,

\[ h_{ii} = \sum_{j=1}^n h_{ij}^2. \]
