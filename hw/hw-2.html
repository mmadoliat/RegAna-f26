Statistical Computing and Data Analysis

Use R (preferred) or another statistical computing environment. All numerical results, tables, confidence intervals, hypothesis tests, and figures in this section should be generated by computer. Include the relevant code.

Automobile gasoline mileage data

The data are the Table B.3 automobile gasoline mileage data used in the regression textbook. The data contain measurements on 32 automobiles.

The dataset is already included in the course data file. In R, load it using

load("./data/regression_datasets.rda")
mpg_data <- table_B3

head(mpg_data)

If your copy of regression_datasets.rda is stored in a different folder, modify the path accordingly.

The variables are:

  • \(y\): miles per gallon
  • \(x_1\): displacement (cubic inches)
  • \(x_2\): horsepower (ft-lb)
  • \(x_3\): torque (ft-lb)
  • \(x_4\): compression ratio
  • \(x_5\): rear axle ratio
  • \(x_6\): carburetor (barrels)
  • \(x_7\): number of transmission speeds
  • \(x_8\): overall length (inches)
  • \(x_9\): width (inches)
  • \(x_{10}\): weight (lb)
  • \(x_{11}\): transmission indicator (\(1=\) automatic, \(0=\) manual)

For this homework, we focus on the simple linear regression relating gasoline mileage \(y\) to engine displacement \(x_1\).

  1. Fit and interpret the model. Fit the simple linear regression model

    \[ Y_i=\beta_0+\beta_1x_{1i}+\varepsilon_i. \]

    Report the fitted regression equation and interpret both estimated coefficients in context. Comment on whether interpretation of the intercept is practically meaningful.

  2. Confidence intervals for model parameters. Construct 95% confidence intervals for

    \[ \beta_0,\qquad \beta_1,\qquad \sigma^2. \]

    For the confidence interval for \(\sigma^2\), use the appropriate chi-square distribution. Show the formula or procedure used.

  3. Test the slope. At significance level \(\alpha=0.05\), test

    \[ H_0:\beta_1=0 \qquad\text{versus}\qquad H_1:\beta_1\neq0. \]

    Clearly report the hypotheses, test statistic, degrees of freedom, \(p\)-value (or rejection rule), decision, and conclusion in context.

  4. ANOVA and significance of regression. Construct the ANOVA table for the fitted model and use it to test the significance of regression at \(\alpha=0.05\). State the hypotheses and conclusion. Explain how this test is related to the slope test in Question 3.

  5. Coefficient of determination. What percentage of the total variability in gasoline mileage is explained by the linear relationship with engine displacement? State and interpret the appropriate statistic.

  6. Confidence interval for the mean response. Find a 95% confidence interval for the mean gasoline mileage among automobiles with engine displacement \(x_1=275\text{ in}^3.\) Interpret the interval in context.

  7. Prediction for a new automobile. Suppose we want to predict the gasoline mileage of a new automobile with a 275 in\(^3\) engine.

    1. Give the point prediction.

    2. Construct a 95% prediction interval.

    3. Compare this prediction interval with the confidence interval from Question 6. Which interval is wider, and why?

  8. Visualize fitted values and uncertainty. Create one figure containing

    • the observed data \(\{(x_{1i},y_i)\}_{i=1}^{32}\),
    • the fitted simple linear regression line,
    • the 95% confidence band for the mean response \(\mu_{Y\mid X=x}\), and
    • the 95% prediction band for a future response \(Y\mid X=x\).

    Use clear axis labels, an informative title, and a legend. The confidence and prediction bands should be visually distinguishable.

    Hint: Create a fine sequence of engine-displacement values over the observed range and use predict() with interval = "confidence" and interval = "prediction".

  9. Verify least-squares properties numerically. Using the observed data and your fitted model, verify the following properties to reasonable numerical precision:

    1. \(\sum_{i=1}^{32}e_i=\sum_{i=1}^{32}(y_i-\hat y_i)=0.\)

    2. \(\sum_{i=1}^{32}y_i=\sum_{i=1}^{32}\hat y_i.\)

    3. The fitted least-squares line passes through the centroid \((\bar x,\bar y).\)

    4. \(\sum_{i=1}^{32}x_{1i}e_i=0.\)

    5. \(\sum_{i=1}^{32}\hat y_i e_i=0.\)

    For each part, show the R calculation and briefly explain why the result is expected from least-squares theory.

Mathematical Derivation and Reasoning

Throughout this section, consider the simple linear regression model

\[ Y_i=\beta_0+\beta_1x_i+\varepsilon_i,\qquad \varepsilon_i\stackrel{\text{iid}}{\sim}N(0,\sigma^2), \]

for \(i=1,\ldots,n\), with the predictor values \(x_1,\ldots,x_n\) treated as fixed.

  1. Unbiasedness of the intercept estimator. Before the sample is observed, the \(Y_i\)’s are random variables. Show that \(b_0\) is an unbiased estimator of \(\beta_0\), that is,

\[ E(b_0)=\beta_0. \]

  1. ANOVA decomposition. Show that

\[ \sum_{i=1}^n(y_i-\bar y)^2 = \sum_{i=1}^n(\hat y_i-\bar y)^2 + \sum_{i=1}^n(y_i-\hat y_i)^2. \]

In other words, show that

\[ SS_T=SS_R+SS_{\mathrm{res}}. \]
